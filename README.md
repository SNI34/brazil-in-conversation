# Brazil, in Conversation

**COMM 317 intercultural communication learning website**

An interactive, research-based exploration of Brazilian culture through five connections to Martin and Nakayama’s *Experiencing Intercultural Communication* (7th ed., 2021). Soccer is included as one part of a wider look at history, identity, language, nonverbal communication, music, everyday life, and cultural reflection.

## View the website

The files in this repository are the complete static website. Enable **GitHub Pages** in **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The site entry point is `index.html`.

To run it locally, download the repository and open `index.html` in a modern browser. Keep the JavaScript, CSS, JSON, and `assets` folder together.

## Contents

- `index.html`, `styles.css`, `app.js`, and `data.js`: the site and interactive lessons
- `brazil-culture-project.json`: structured project content and references
- `assets/`: six locally bundled photographs

The site also credits photographs and scholarly/institutional sources on its Sources page. Some credited images are loaded from their source websites, so they require an internet connection.
